# Сайт Owl-IN

Для Owl-IN готовится отдельный сайт-визитка, который не является частью приложения Owl-IN ServiceKit и не входит в его EXE.

## Назначение

Сайт нужен как публичная страница бренда **Owl-IN** и точка входа для пользователей Owl-IN ServiceKit. На нём планируется показывать только актуальное состояние продукта без публикации внутренних планов разработки.

Основные задачи сайта:

- кратко объяснить, что такое Owl-IN ServiceKit;
- показать реальные скриншоты Easy Mode и Expert Mode;
- перечислить основные возможности;
- дать прямую ссылку на актуальный GitHub Release;
- показать версию и SHA-256 релизного EXE;
- дать ссылки на GitHub и документацию;
- ответить на основные вопросы по запуску и работе программы.

## Структура

Сайт проектируется как страница бренда **Owl-IN**, где Owl-IN ServiceKit является текущим опубликованным продуктом. Такая структура не привязывает сам сайт к имени одного приложения.

Для публикации выбран отдельный репозиторий:

```text
Owl-IN-ex/Owl-IN-ex.github.io
```

После публикации основной адрес GitHub Pages будет:

```text
https://owl-in-ex.github.io/
```

## Текущее состояние

Разработка ведётся сначала локально. Первый локальный прототип уже собран в виде статического сайта без внешних библиотек и CDN.

В текущем прототипе есть:

- главная секция Owl-IN ServiceKit;
- реальные скриншоты приложения;
- описание Easy Mode и Expert Mode;
- блок основных возможностей;
- кнопка скачивания текущего релиза;
- SHA-256 с копированием;
- FAQ;
- адаптация под мобильные устройства.

Публикация на GitHub Pages выполняется только после локальной проверки и согласования внешнего вида.

## Разделение с Owl-IN ServiceKit

Репозиторий Owl-IN ServiceKit остаётся источником релизов, документации и технической информации о программе. Сайт выполняет роль внешней публичной страницы и ведёт пользователя на соответствующие разделы GitHub, а не дублирует репозиторий целиком.
