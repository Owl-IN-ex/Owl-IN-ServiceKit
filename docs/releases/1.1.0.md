# Owl-IN ServiceKit 1.1.0

Дата выпуска: **22 сентября 2026 года**.

## Главное

- проверка фактического доступа к сайтам с учётом пользовательского WinINET proxy/PAC;
- обнаружение и отключение недоступного proxy, оставшегося после VPN;
- повторная проверка соединения после исправления;
- прямые действия восстановления в Easy Mode;
- обычная перезагрузка, переход к дополнительным параметрам запуска и отмена запланированной перезагрузки;
- запуск штатного восстановления системы и параметров восстановления Windows;
- корректное отображение состояния запланированной ServiceKit перезагрузки;
- более компактный экран Recovery без лишних справочных блоков.

## Важно

Сборка не подписана сертификатом Authenticode. Windows SmartScreen может показать предупреждение неизвестного издателя.

Автоматической замены EXE нет. Пользователь вручную скачивает новый выпуск и заменяет предыдущий файл.
