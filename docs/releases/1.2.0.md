# Owl-IN ServiceKit 1.2.0

Дата подготовки: **25 сентября 2026 года**.

## Основное

- Easy Mode получил реальные действия для сети, Wi-Fi, Windows Update, звука, Bluetooth, устройств, диска, памяти и тяжёлых процессов.
- После исправления повторяется исходная проверка; успешный результат показывается только после подтверждения эффекта.
- Добавлен Reboot/Resume: ServiceKit сохраняет операцию, продолжает проверку после входа в Windows и удаляет одноразовую задачу после завершения.
- Windows Memory Diagnostic подключена к механизму продолжения и истории Repair Engine.

## Recovery и откаты

- Expert Recovery показывает отдельные точки отката DNS, WinINET, WinHTTP и PendingFileRenameOperations.
- Можно выбрать конкретный backup для восстановления.
- Добавлено выборочное удаление точек отката через переключаемый режим с иконкой корзины.
- PendingFileRenameOperations можно просмотреть, безопасно очистить с backup и восстановить.
- Системные окна подтверждения заменены собственным диалогом Owl-IN ServiceKit.

## Диагностика

- Исправлен анализ больших UTF-8 `hosts`; блокировки, перенаправления и некорректные адреса считаются отдельно.
- Абсолютные пути в интерфейсе стали кликабельными.
- Настройки CrashControl в RAM/BSOD получили понятные названия и пояснения.
- Улучшено обнаружение остаточного proxy/PAC и DNS-проблем после VPN.

## Безопасность изменений

- Контролируемые изменения DNS, proxy и PendingFileRenameOperations используют backup и проверку результата; при неудаче предусмотрен откат.
- Необратимые действия требуют отдельного подтверждения.
- Backend проверяет выбранные точки отката и не принимает произвольные пути.

## Windows SmartScreen

Релизный EXE пока не подписан сертификатом Code Signing. Поэтому Windows может показать предупреждение SmartScreen или статус **«Неизвестный издатель»**. Само сообщение о неизвестном приложении относится к репутации файла и издателя, а не к обнаружению угрозы Microsoft Defender Antivirus. Подробнее: [документация Microsoft о репутации SmartScreen](https://learn.microsoft.com/windows/apps/package-and-deploy/smartscreen-reputation).
