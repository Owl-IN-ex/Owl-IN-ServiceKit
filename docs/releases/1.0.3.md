# Owl-IN ServiceKit 1.0.3

Первая публичная сборка Owl-IN ServiceKit в GitHub Releases.

## Основное

- portable-запуск из одного EXE без установки;
- режим **Easy** с Quick Scan и сценариями «У меня проблема»;
- режим **Expert** с расширенной технической диагностикой;
- проверки сети, DNS, proxy, VPN/TUN и компонентов, влияющих на соединение;
- диагностика накопителей, RAM/BSOD, Windows Update, служб, автозапуска и событий Windows;
- анализ подозрительной фоновой активности и persistence;
- безопасная изоляция подозрительных объектов с возможностью восстановления;
- адаптивное окно и боковая навигация для разных размеров рабочей области;
- корректное разворачивание окна без перекрытия панелью задач Windows.
