# Owl-IN ServiceKit 1.2.1

Выпуск улучшает работу в области уведомлений и проверку резервных копий перед изменением Windows.

## Область уведомлений

- Закрытие окна крестиком сворачивает приложение в трей; для завершения используйте «Выйти».
- Нажатие на значок или команда «Открыть» возвращает окно. Повторный запуск открывает уже работающий экземпляр.
- Меню трея оформлено в стиле Owl-IN: скруглённые углы, ровные отступы, синяя подсветка «Открыть» и красная подсветка «Выйти».
- При первом закрытии показывается уведомление о продолжении работы в трее.

## Резервные копии и откат

- JSON-backup записываются атомарно через временный файл; после записи проверяются чтение, схема и SHA-256.
- Для WinHTTP проверяются наличие и содержимое текстовой резервной копии.
- Изменение Windows не начинается, если резервная копия отсутствует, пуста, недоступна или не прошла проверку.
- Уникальные имена резервных копий предотвращают перезапись при быстрых или параллельных действиях.

## Запуск и проверка файла

Скачайте `Owl-IN-ServiceKit-1.2.1.exe` и запустите его. Установка не требуется. Перед запуском новой версии завершите старую через «Выйти» в меню трея.

```text
Owl-IN-ServiceKit-1.2.1.exe
SHA-256: f051f13315c9dd76aeb25e57255607cae498b09203e580080e8812ef5abebc66
```

EXE пока не подписан сертификатом Code Signing. Windows может показать предупреждение SmartScreen или «Неизвестный издатель»; файл следует скачивать из официального релиза и при необходимости сверять SHA-256.
