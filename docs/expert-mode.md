# Expert Mode

Expert Mode используется для технического анализа и ручных сервисных действий.

## Текущие разделы

- обзор системы;
- конфигурация;
- сеть;
- накопители;
- RAM / BSOD;
- Windows Update;
- службы и автозапуск;
- события Windows;
- безопасность;
- Recovery;
- RAW / evidence;
- отчёты и история.

## Принцип отображения

Expert Mode показывает не только команды и JSON, но и интерпретацию:

- факт;
- правило срабатывания;
- влияние;
- доказательства;
- следующая полезная проверка.

RAW-данные остаются доступными как отдельный технический уровень.
