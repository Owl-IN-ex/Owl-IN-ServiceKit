# Монитор процессов

Expert Mode → Процессы: собственный сбор Get-Process, CIM Windows и IP Helper API. Task Manager не запускается и не используется как источник.

Сортировка списка меняется кликом по заголовку столбца: повторный клик переключает возрастание / убывание. Стрелка показывает текущий порядок. Числовые столбцы сначала показывают большие значения, имена — по алфавиту; недоступные измерения остаются в конце при любом направлении. Поиск и показ защищённых процессов работают независимо от сортировки.

CPU измеряется по приросту TotalProcessorTime в двух интервалах около 900 мс и делится на число логических процессоров: 100% означает всю мощность компьютера. Для сопоставления проверяется время создания процесса. Общий CPU отдельно читается через Win32_PerfFormattedData_PerfOS_Processor. При недоступной общей загрузке предложение завершения по CPU не создаётся.

RAM — WorkingSet, не весь commit / private memory. GPU — самый занятый движок процесса по Win32_PerfFormattedData_GPUPerformanceCounters_GPUEngine. VRAM и shared GPU memory берутся из GPUProcessMemory. Значения зависят от драйвера / WDDM, могут отличаться от физического потребления и не служат диагнозом; shared memory различных процессов нельзя суммировать как общую занятую RAM.

Список TCP-соединений получен через Get-NetTCPConnection, включает IPv4 / IPv6, адреса, порты, состояние и время создания. Он не является измерением скорости. UDP / QUIC не включены.

Автоматическая выборка скорости читает только уже включённую IPv4 TCP EStats Data. Кнопка «Измерить TCP-трафик · 1 с» временно включает статистику максимум 128 существующих соединений выбранного процесса и возвращает исходное состояние в finally. Уже включённые счётчики не отключаются. Требования Windows к правам сохраняются, UAC автоматически не запрашивается. Возвращаются отдельно число увиденных / измеренных IPv4-соединений и число ошибок восстановления. Закрывшиеся, новые, IPv6, UDP и QUIC не входят в скорость. Это частичное измерение TCP, а не полный интернет-трафик приложения.

Маршрут PTR остаётся во внутреннем backend, но в текущем интерфейсе не вызывается; адреса соединений не показываются. Никакого перехвата HTTPS.

Сведения о файле и Authenticode автоматически читаются при выборе строки для выбранного PID и времени старта; кнопку во вкладке «Файл» можно использовать для повторного чтения. CompanyName — неподтверждённая строка метаданных; действительная подпись не доказывает безопасность приложения.

## Завершение

Действие доступно только для процесса текущего пользователя, когда известны PID, имя, время создания и путь, IsProcessCritical вернул false и процесс не обслуживает службу. Критические процессы Windows и ServiceKit / WebView защищены. При действии всё проверяется повторно; недоступное время создания, владелец, сведения о службах приводят к отказу. Stop-Process получает привязанный Process object. После действия подтверждается исчезновение исходного экземпляра, а не «излечение программы». Несохранённые данные могут быть потеряны; требуется подтверждение пользователя.

Easy Mode при общей нагрузке CPU >90% в двух пробах предлагает максимум 3 процесса с CPU >=20% в каждом интервале. Самый большой потребитель RAM не выбирается как причина загрузки CPU. При свободной RAM <10% предлагаются максимум 3 процесса с WorkingSet >=max(256 МБ,10% RAM). Можно открыть собственный список процессов. Порог не доказывает неисправность: нормальный рендеринг или игра также создают нагрузку.

## Проверка

`powershell -File tools/tests/ProcessMonitor.Tests.ps1`: расчёт CPU, смена PID, неизвестные показатели, различие CPU / RAM кандидатов, запрет завершения защищённых / чужих / служебных процессов, смена времени создания и проверка результата. Завершение полностью mocked, реальные процессы не закрываются.

`node tools/tests/processes-ui.test.cjs`: фильтр, сортировка, неизвестные значения, защита и HTML-escaping. Отдельная сценарная сборка содержит три примера монитора; завершение, сведения о файле, PTR и трафик в ней только вымышленные.

Реальное чтение проверено на рабочем компьютере. Реальное завершение и последующая проверка выполнены на собственном временном PowerShell-процессе; приложения пользователя не закрывались. Собственное IPv4-соединение 127.0.0.1 было обнаружено, однако счётчики без необходимых прав недоступны: скорость остаётся null, ошибок возврата состояния нет. Положительное измерение EStats с временным включением требует ручной проверки в подходящем окружении с правами администратора.

Подробности открываются кликом по любой ячейке строки; кнопка имени также доступна с клавиатуры. Во вкладке «Сеть» сведения относятся только к выбранному PID, не ко всему браузеру. TCP отсутствует в таблице. Во вкладке «Сеть» видны только отправка, получение и кнопка измерения частичного TCP-трафика; списка адресов и раскрываемого блока нет. Нулевой результат короткой пробы не означает отсутствие интернет-трафика приложения.

В подробностях ресурсов технические названия сопровождаются простыми пояснениями CPU, RAM, GPU, VRAM и RAM для графики. Предыдущая проба CPU скрыта из интерфейса; обе пробы сохраняются для диагностической логики.

При выборе строки автоматически читаются название продукта, описание, компания и подпись локального файла. Версия и родительский процесс доступны во вкладке «Файл». Метаданные файла не подтверждают назначение или безопасность. Родитель показывается только при совпадении экземпляра дочернего процесса и времени запуска родителя не позже дочернего; завершённый родитель не восстанавливается по одному PID.
