# Easy Mode

Easy Mode — слой для пользователя, которому не нужны Event ID, PNPDeviceID, имена служб и сырые JSON-данные.

## Принцип

Пользователь выбирает симптом, а не техническую подсистему.

Примеры сценариев:

- интернет не работает;
- сайты не открываются / ошибка DNS;
- после VPN пропал интернет;
- Wi-Fi не работает;
- Windows Update не работает;
- Windows тормозит или зависает;
- нет звука;
- Bluetooth не работает;
- принтер не печатает;
- проблема с устройством или драйвером;
- мало места или проблема с диском;
- синий экран / перезагрузка / память;
- подозрительная фоновая нагрузка.

## Что показываем

Основной результат отвечает на четыре вопроса:

1. Что найдено?
2. Почему это важно?
3. Что можно сделать?
4. Помогло ли действие после повторной проверки?

Технические доказательства доступны через «Показать технические детали» или в Expert Mode.

## Подозрительная активность

Easy не показывает полноценный диспетчер процессов. Сценарий самостоятельно анализирует совокупность признаков: нагрузку, путь к файлу, подпись, persistence, сетевые соединения и другие факторы.

При достаточной уверенности Owl-IN ServiceKit может предложить безопасное обезвреживание.

## Repair

Для автоматических исправлений используется безопасная последовательность:

**Backup → Fix → Verify → Rollback**
