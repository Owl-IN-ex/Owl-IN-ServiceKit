# Owl-IN ServiceKit — история версий

## 1.2.0 — 2026-09-25

- Easy Mode получил реальные действия для сети, Wi-Fi, Windows Update, звука, Bluetooth, устройств, диска, памяти и тяжёлых процессов.
- После исправления повторяется исходная проверка; успешный результат показывается только после подтверждения эффекта.
- Добавлен Reboot/Resume: незавершённая операция продолжается после входа в Windows и получает итоговую проверку.
- Expert Recovery показывает отдельные точки отката DNS, WinINET, WinHTTP и PendingFileRenameOperations.
- Добавлены выбор конкретной точки отката и режим их выборочного удаления.
- PendingFileRenameOperations можно просмотреть, очистить с предварительным backup и восстановить.
- Системные окна подтверждения заменены собственным диалогом Owl-IN ServiceKit.
- Исправлен анализ больших UTF-8 `hosts`; абсолютные пути в интерфейсе стали кликабельными.
- Улучшено обнаружение остаточного proxy/PAC и DNS-проблем после VPN.
- Контролируемые изменения используют backup, проверку результата и откат при неудаче.

## 1.1.0 — 2026-09-22

- Проверка интернета теперь учитывает пользовательский WinINET proxy/PAC и фактическое открытие сайта.
- Недоступный proxy, оставшийся после VPN, больше не считается исправным подключением и показывается как причина проблемы.
- Добавлено действие отключения пользовательского proxy с повторной проверкой соединения.
- Исправлена ошибка `Типы аргумента не совпадают` в сетевом исправлении под Windows PowerShell 5.1.
- Easy-раздел «Восстановление» получил прямые действия: обычную перезагрузку, дополнительные параметры запуска, восстановление системы, параметры восстановления Windows и отмену перезагрузки.
- После запуска перезагрузки отображается состояние **«Запланирована»**; оно очищается после отмены или следующей загрузки Windows.
- Диагностика Recovery перенесена ниже действий и свёрнута по умолчанию; лишние справочные блоки удалены.
- Обозначение Functional Test удалено из интерфейса и пользовательских сведений о версии.

## 1.0.4 — 2026-09-20

- В раздел «О программе» добавлены официальный сайт Owl-IN и ручная проверка обновлений.
- Проверка нового выпуска стала быстрее и устойчивее при недоступности отдельных источников.
- История Quick Scan теперь работает непосредственно в EXE и хранится между запусками.
- Добавлены ротация журналов и очистка старых временных файлов и runtime-кэшей.
- Окно учитывает рабочую область монитора и не уходит под панель задач Windows.
- Восстановлена финальная компоновка меню: при небольшой высоте пункты становятся компактнее, список прокручивается, а нижняя кнопка остаётся доступной.
- Встроенный интерфейс обновляется при изменении содержимого сборки и не использует устаревший локальный кэш.
- Версии продукта, EXE, launcher и runtime синхронизированы для релиза 1.0.4.

## 1.0.3 — 2026-09-19

- Подготовлена релизная сборка без маркировки Functional Test; пользовательская версия отображается как **1.0.3 Release**.

## 1.0.3 — 2026-09-19

- Подготовлена релизная сборка без маркировки Functional Test; пользовательская версия отображается как **1.0.3 Release**.
- Унифицировано официальное имя продукта: во всех пользовательских текстах используется **Owl-IN ServiceKit**.
- Финальный portable-файл формируется с версией в имени: `Owl-IN-ServiceKit-1.0.3.exe`.
- Синхронизированы Product Name, версия, launcher, runtime-каталог и сообщения сборщика.
- Встроенные UI-ресурсы и backend теперь проверяются по SHA-256 содержимого, поэтому повторная сборка той же версии не подхватывает устаревший кэш.
- Исправлена компоновка при изменении высоты окна: рабочая область и список разделов имеют независимую прокрутку.
- Исправлено левое меню Expert Mode: список разделов прокручивается отдельно, а управление боковой панелью остаётся доступным.
- Исправлено разворачивание окна с собственной рамкой: окно учитывает рабочую область монитора и не уходит под панель задач Windows.
- Убрана лишняя декоративная подпись под боковым меню и добавлен нормальный нижний отступ у кнопки сворачивания.

## 1.0.2 — 2026-09-19

- Исправлены визуальные артефакты, обрезание секций и градиентных световых зон при быстром переключении разделов.
- Удалены `content-visibility:auto` и paint containment для рабочей области: они оказались нестабильными при частой замене DOM в WebView2.
- Навигация теперь коалесцирует быстрые клики и отрисовывает только последний выбранный раздел.
- При переходе между страницами позиция прокрутки гарантированно сбрасывается до начала нового раздела.
- Автоматический запуск тяжёлой Expert-диагностики отложен и отменяется, если пользователь уже ушёл с раздела.
- Старт диагностики больше не вызывает дополнительную полную перерисовку Expert-страницы.
- Фоновые световые зоны рабочей области вынесены в стабильный слой, независимый от содержимого текущей страницы.

## 1.0.1 — 2026-09-19

- Ускорены переходы между разделами и снижена нагрузка WebView2 на больших Expert-экранах.
- PowerShell-диагностика вынесена из UI-потока и сериализована: тяжёлые проверки не запускаются параллельно при быстром переключении разделов.
- RAW JSON теперь формируется только по запросу пользователя.
- Боковая навигация больше не пересоздаётся целиком при каждом переходе.
- Доработана portable-упаковка в один распространяемый EXE с внутренним runtime-кэшем.
- Синхронизированы Product/File/Assembly/Informational Version, launcher и runtime-каталог.
