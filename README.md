# Owl-IN ServiceKit

**Owl-IN ServiceKit** — portable-утилита для диагностики и аккуратного восстановления Windows 10/11.

Текущая логика работы:

**Detect → Explain → Backup → Fix → Verify → Rollback**

## Что уже умеет

- быстрый Quick Scan компьютера;
- режим **Easy** с понятными сценариями «У меня проблема»;
- режим **Expert** с технической диагностикой;
- проверка сети, DNS, proxy, VPN/TUN и компонентов, влияющих на соединение;
- диагностика накопителей, RAM/BSOD, Windows Update, служб, автозапуска и событий Windows;
- анализ подозрительной фоновой активности и persistence;
- безопасная изоляция подозрительных объектов с возможностью восстановления;
- portable-запуск из одного EXE без установки.

## Easy и Expert

**Easy Mode** нужен, когда не хочется разбираться в Event ID, службах и реестре. Выбираешь симптом — **Owl-IN ServiceKit** собирает данные, объясняет, что найдено, и предлагает доступные безопасные действия.

**Expert Mode** оставляет технические детали: доказательства, конфигурацию, сеть, события, безопасность, RAW-данные и ручные инструменты.

## Сборка

Проект использует **.NET 8**, WPF и WebView2. Для локальной Windows-сборки используется `BUILD-EXE.cmd`.

Техническая документация находится в [`docs/`](docs/). Рабочий список запланированных задач вынесен отдельно в [ROADMAP.md](ROADMAP.md) и может меняться по ходу разработки.
