# Owl-IN ServiceKit

**Owl-IN ServiceKit** — portable-утилита для диагностики и аккуратного восстановления Windows 10/11.

Идея простая: не просто показать очередную ошибку Windows, а пройти нормальный путь от проблемы до результата:

**Detect → Explain → Backup → Fix → Verify → Rollback**

## Что уже умеет

- быстрый Quick Scan компьютера;
- режим **Easy** с понятными сценариями «У меня проблема»;
- режим **Expert** с технической диагностикой;
- проверка сети, DNS, proxy, VPN/TUN и компонентов, влияющих на соединение;
- диагностика накопителей, RAM/BSOD, Windows Update, служб, автозапуска и событий Windows;
- анализ подозрительной фоновой активности и persistence;
- безопасная изоляция подозрительных объектов с возможностью восстановления;
- portable-запуск из одного EXE без установки.

## Easy и Expert

**Easy Mode** нужен, когда не хочется разбираться в Event ID, службах и реестре. Выбираешь симптом — ServiceKit сам собирает данные, объясняет, что нашёл, и предлагает безопасные действия.

**Expert Mode** оставляет всю техническую кухню: доказательства, конфигурацию, сеть, события, безопасность, RAW-данные и ручные инструменты.

## Текущая версия

**1.0.3** — стабильная база проекта.

Готовый EXE не хранится в исходниках репозитория. Публичные сборки будут лежать в **GitHub Releases**.

## Куда идём дальше

В ближайших крупных этапах:

- собственный диспетчер процессов в Expert Mode;
- единый Repair / Backup / Verify / Rollback Engine;
- продолжение операций после перезагрузки;
- Rules Engine и база интерпретации Windows Event Log;
- аппаратные датчики и расширенная диагностика драйверов;
- Security 2.0;
- режим «Наблюдение за системой» — запись цепочки процессов, файлов, реестра, служб и сети во время воспроизведения проблемы.

Подробный план: [ROADMAP.md](ROADMAP.md).

## Сборка

Проект использует **.NET 8**, WPF и WebView2. Для локальной Windows-сборки есть `BUILD-EXE.cmd`.

Подробности архитектуры и логики лежат в [`docs/`](docs/).

---

Проект развивается как практичная сервисная утилита, а не как «оптимизатор Windows» с сотней сомнительных галочек.
