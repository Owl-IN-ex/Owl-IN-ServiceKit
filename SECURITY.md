# Security

**Owl-IN ServiceKit** работает с системной диагностикой, процессами, службами, сетевыми настройками и механизмами восстановления. Для автоматических действий действует принцип: **сначала понять, потом менять**.

## Базовые правила

- один слабый признак не считается достаточным основанием для удаления или изоляции объекта;
- изменения по возможности проходят через Backup → Fix → Verify → Rollback;
- критические системные процессы и компоненты требуют дополнительной защиты от случайного вмешательства;
- Safe Mode не включается автоматически;
- наличие VPN, WinDivert, unsigned-файла или Defender exclusion само по себе не означает вредоносность;
- Owl-IN ServiceKit не позиционируется как полноценный антивирус.

## Отчёты и данные

Локальные логи, история диагностики, карантин и резервные копии не должны попадать в git.

## Сообщить об уязвимости

Не публикуйте потенциально опасные детали в открытом Issue. Для таких сообщений используйте прямой контакт с владельцем репозитория через GitHub-профиль.
